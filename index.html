Dosing is drawn from the Paediatric Protocols for Malaysian Hospitals (5th Edition, Oct 2025), the National Antimicrobial Guideline (NAG) Malaysia, NeoFax (IBM Micromedex) and Frank Shann's Drug Doses (17th Ed.).

NAGPP5NF/FS — show which reference each figure follows.

Displayed doses are rounded up to the nearest whole number where the value is ≥1 (for ease of drawing up) — always sanity-check against the per-kg figure shown in the label.

Have pharmacy/neonatology confirm before bedside use. Figures were transcribed/cross-referenced and could contain errors — please report anything that looks off.

Patient list (name, GA, DOB, weight) is stored locally on this device only (never sent anywhere) so your ward list survives closing the app. Delete a patient any time from the home screen to remove them from this device.

The drug database is read-only in this app — there is no way to add, edit, or delete a drug here, by design, to prevent tampering. It auto-syncs in the background from a single shared Google Sheet; all real edits happen there. If this device has never synced or has no internet, it falls back to the version built into the app at time of install.
