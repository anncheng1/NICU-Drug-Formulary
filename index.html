Working draft — verify before clinical use

Dosing follows the Hospital Miri Paediatric Dosing Guide 2026 (Pharmacy & Paediatric Departments; 3rd draft, 16 Sep 2026) where it covers a drug, then the Paediatric Protocols for Malaysian Hospitals (5th Edition, 2025), the National Antimicrobial Guideline (NAG) Malaysia, NeoFax (IBM Micromedex) and the Australasian Neonatal Medicines Formulary (ANMF).

NAGPP5MGHNF/ANMF — show which reference each figure follows.

Displayed doses are rounded up to the nearest whole number where the value is ≥1 (for ease of drawing up) — always sanity-check against the per-kg figure shown in the label.

Have pharmacy/neonatology confirm before bedside use. Figures were transcribed/cross-referenced and could contain errors — please report anything that looks off.

Patient list (name, GA, DOB, weight) is stored locally on this device only (never sent anywhere) so your ward list survives closing the app. Delete a patient any time from the home screen to remove them from this device.

The drug database is read-only in this app — there is no way to add, edit, or delete a drug here, by design, to prevent tampering. It is published from the unit's GitHub repository as drugs.csv; uploading a new drugs.csv there is the only way to change a dose. Every device checks for a new file when the app opens, when it returns to the foreground, when the connection comes back and every 15 minutes. A device that has never connected uses the copy built into the app.

Works offline. After the first open with internet, the app and the latest drug list are stored on this device. Add it to your home screen (iPhone: Share → Add to Home Screen · Android: ⋮ → Install app) to use it like a normal app on the ward.
